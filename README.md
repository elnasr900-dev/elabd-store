# العبد للدراجات النارية

واجهة متجر عربية RTL تعمل بـ Node.js بدون حزم خارجية.

## التشغيل

1. افتح المجلد في Visual Studio Code.
2. افتح الطرفية داخل المجلد.
3. شغّل `npm start`.
4. افتح `http://localhost:3000` في المتصفح.

## ملاحظات

- إنشاء الحساب وتسجيل الدخول يستخدمان رقم هاتف مصري وكلمة مرور؛ كلمات المرور تُحفظ كقيمة مشتقة باستخدام `scrypt` في `data/users.json`.
- بيانات الدخول تحفظ في جلسة ذاكرة مؤقتة، وتنتهي عند إعادة تشغيل السيرفر.
- التسجيل في السحب يُحفظ في `data/raffle-entries.json`، ويسمح لكل رقم هاتف بدخول كل جائزة مرة واحدة.
- الموديلات والأسعار المعروضة أمثلة قابلة للتعديل في `server.js` و`public/app.js`.
- حاسبة التقسيط تقديرية: أصل المبلغ + فائدة بسيطة 20% لكل سنة، موزعة على عدد الشهور المختار.
- غيّر رابط صفحة فيسبوك وموقع المعرض في `public/index.html` عندما تكون جاهزة.
- صورة الإعلان محفوظة في `public/assets/el-abd-store-ad.jpg`.
- صور الـ32 موديل المستخرجة من ملف PDF محفوظة كل واحدة كصورة مستقلة في `public/assets/` وتظهر كمربعات داخل قسم المنتجات.
